<objective>
## Goal
Improve test command output formatting with better progress indicators, structured results, and human-readable formatting for the verify command.

## Purpose

Make test output more useful for AI agents by providing clearer progress indication, better structured data, and formatted results that are easier to parse and understand.

## Output

- Progress indicators during test execution
- Formatted test output with clear pass/fail indicators
- Structured test result parsing
- Human-readable summary formatting
  </objective>

<acceptance_criteria>

## AC-1: Progress Indicators

Given the verify command is running tests
When tests are executing
Then display progress indicator (spinning or "Running...")
And update status bar with "verify: testing..." during execution

## AC-2: Formatted Test Output

Given tests have completed
When displaying results to user
Then show formatted output with checkmarks/X marks
And include duration for each test file
And highlight failures in red/success in green (if TUI supports)

## AC-3: Test Result Parsing

Given test output from common frameworks (Jest, Vitest, node:test)
When parsing test results
Then extract: pass count, fail count, skip count, test names
And include parsed results in VerifyResult details

## AC-4: Human-Readable Summary

Given all checks complete
When formatting final output
Then display summary table:
✓ Typecheck: 2s
✓ Test: 15s (42 passed, 0 failed)
✗ Lint: 3s (12 errors)
And show total duration
</acceptance_criteria>
