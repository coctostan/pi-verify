<objective>
## Goal

Test explicit two-step dispatch: advisory modules (IRIS, RUBY, DOCS, SKIP) output
BEFORE enforcement modules (WALT) issue blocks.

## Purpose

Validate that advisory annotations are collected and visible even when WALT will
ultimately block the APPLY.

## Output

Demonstration of two-step dispatch behavior with advisory output visible before
enforcement block.
</objective>

## Two-Step Dispatch Pattern

Step 1: advisory_module_dispatch (p200-p300)

- IRIS: code smells, security patterns
- RUBY: debt flags
- DOCS: drift detection
- SKIP: knowledge extraction

Step 2: enforcement_module_dispatch (p100)

- WALT: lint/type checks → BLOCK if violations

Expected: Advisory output visible before block enforcement.
</context>
