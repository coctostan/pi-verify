<objective>
## Goal
Add `.verifyrc.json` configuration support for customizing check commands per project, and implement parallel check execution for faster verification runs.

## Purpose

Users need to override default check commands for their specific project setup. Running checks sequentially is slow—parallel execution reduces verification time significantly.

## Output

- Configuration loader module with JSON schema validation
- Updated verify runner that respects custom commands from `.verifyrc.json`
- Parallel execution for independent checks (typecheck, lint, format can run in parallel; test often needs to wait)
- Comprehensive tests for configuration loading and parallel execution
  </objective>

    Create src/config.ts with:
    - Define VerifyConfig interface with optional overrides per language and check type:
      ```typescript
      interface VerifyConfig {
        commands?: Partial<Record<ProjectType, Partial<Record<CheckType, string>>>>;
        parallel?: boolean; // default true
      }
      ```
    - loadConfig(cwd: string): Promise<VerifyConfig | null> — reads .verifyrc.json if exists
    - validateConfig(config: unknown): VerifyConfig — validates shape, throws on invalid
    - mergeWithDefaults(
        projectType: ProjectType,
        check: CheckType,
        config: VerifyConfig | null,
        scripts?: Record<string, string>
      ): string | null — returns final command to execute

    - Loading when file doesn't exist returns null
    - Invalid config throws descriptive error
    - mergeWithDefaults uses custom command when specified
    - mergeWithDefaults falls back to defaults when not specified
    - mergeWithDefaults falls back to package.json scripts for nodejs
