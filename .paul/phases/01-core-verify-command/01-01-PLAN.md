<objective>
## Goal
Implement the `/verify` command with `all`, `test`, `lint`, and `quick` subcommands for Node.js projects. Provide a `verify_check` tool for model-callable verification. Update status bar with last check results.

## Purpose

Enable AI coding agents to run unified verification checks with structured pass/fail output, eliminating the need to manually run and parse individual command output.

## Output

- `/verify` command with 4 subcommands
- `verify_check` tool for programmatic access
- Node.js project auto-detection
- Structured JSON output for all checks
- Status bar integration showing last result
  </objective>

## AC-2: All Subcommand

```gherkin

Then execute typecheck, test, lint, and build checks sequentially

```

## AC-3: Test Subcommand

```gherkin
Given a Node.js project with package.json
When user runs "/verify test"
Then execute only the test check (npm test or package.json scripts.test)
And return structured JSON with pass/fail status
```

## AC-4: Lint Subcommand

```gherkin
Given a Node.js project with package.json
When user runs "/verify lint"
Then execute lint and format checks
And return structured JSON with pass/fail status
```

## AC-5: Quick Subcommand

```gherkin
Given a Node.js project with package.json
When user runs "/verify quick"
Then execute typecheck and lint only (fastest feedback)
And return structured JSON with pass/fail status
```

## AC-6: Verify Check Tool

```gherkin
Given the extension is loaded
When model calls verify_check tool with { scope: "all" | "test" | "lint" | "quick" }
Then execute the corresponding verification checks
And return structured JSON result with success boolean and details
```

## AC-7: Project Detection

```gherkin
Given the current working directory
When verification runs
Then detect if Node.js project exists (package.json present)
And use package.json scripts to determine available checks
And fail gracefully with clear message if not a Node.js project
```

```gherkin

When checks complete
```

       - build: 'build' script
       - quick: runs typecheck + lint only
       - all: runs typecheck + test + lint + format (skip build for speed)

    5. Parse package.json scripts to determine available checks
    6. Return structured results with timing and output capture
