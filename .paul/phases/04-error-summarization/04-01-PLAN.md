<objective>
## Goal
Implement comprehensive error summarization that aggregates, categorizes, and presents verification errors in a clear, actionable format.

## Purpose

Help AI agents and developers quickly understand what went wrong across all verification checks without manually parsing raw output.

## Output

- Error aggregation across all check types
- Error categorization (syntax, test failure, lint violation, type error)
- Actionable summary with suggested fixes
- Colored error output using chalk
  </objective>

<acceptance_criteria>

## AC-1: Error Aggregation

Given multiple verification checks have run
When one or more checks fail
Then aggregate all errors into a single structured report
And include check type, error message, and file location if available

## AC-2: Error Categorization

Given errors from verification checks
When analyzing error output
Then categorize errors by type:

- SyntaxError: Parse errors, invalid syntax
- TypeError: TypeScript type errors
- TestFailure: Failed test assertions
- LintViolation: ESLint/Prettier violations
- ConfigError: Missing config, invalid setup
  And include category in error summary

## AC-3: Actionable Summary

Given errors have been categorized
When displaying final output
Then show actionable summary:

- "✗ 3 errors found (2 type errors, 1 lint violation)"
- Grouped by category with file paths
- Suggested fix if pattern is recognized

## AC-4: Colored Error Output

Given chalk is available
When displaying errors
Then use colors:

- Red for errors
- Yellow for warnings
- Gray for file paths
- White for error messages

## AC-5: Tool Integration

Given verify_check tool is called
When errors exist
Then return structured error summary in details
And include formatted error text in content
</acceptance_criteria>
